Admin Panel

महत्वपूर्ण सुरक्षा सूचना: यह शुरुआती डेमो Admin पेज है। इसमें वास्तविक लॉगिन/सर्वर सुरक्षा नहीं है और डेटा केवल इसी ब्राउज़र के localStorage में सेव होता है। इसे पब्लिक वेबसाइट पर ऐसे ही अपलोड न करें। सार्वजनिक साइट के लिए Firebase Authentication/Firestore या सुरक्षित सर्वर-साइड Admin Panel जोड़ना जरूरी है।

Saved stories

वीडियो जोड़ने का तरीका

  1. वीडियो को अपनी वेब होस्टिंग या उचित वीडियो स्टोरेज पर अपलोड करें।
  2. ऐसा HTTPS URL लें जो वीडियो को सार्वजनिक रूप से चला सके।
  3. URL को ऊपर Video URL में पेस्ट करें।
  4. Save Story दबाएँ और होम पेज पर प्ले करके जाँचें।

इस डेमो में सीधे बड़ी वीडियो फाइल अपलोड नहीं होती। केवल वीडियो URL सेव होता है।
